Errands privacy policy

Errands is a private tool used only by its owner.

  • It reads emails the owner sends to their own address to add tasks, then labels and archives those emails.
  • It stores tasks in a Google Sheet in the owner's own Google account.
  • Task text may be sent to the Claude API (Anthropic) to sort it into categories. Nothing else is shared.
  • No data is sold, used for advertising, or shared with anyone else.

Google user data is handled in line with the Google API Services User Data Policy, including the Limited Use requirements.
